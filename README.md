# Hackathon App

Environnement de développement prêt pour la production basé sur les Dev Containers VS Code.

## Lancer le projet

1. Ouvrir le dossier dans VS Code.
2. Lorsque l'invite apparaît (ou via `F1` / `Ctrl+Shift+P`), sélectionner **Dev Containers: Reopen in Container**.
3. VS Code démarre automatiquement la stack Docker et s'y connecte.
